Stores info pertaining to a single request made to [`ExecutorResourceMgr`](../classes/executorresourcemgr), including its `request_id`, min and max possible resource grants, actual resource_grant, and various timing stats.

In future work it is planned to use these stats to allow the [`ExecutorResourceMgr`](../classes/executorresourcemgr) to learn from query patterns and timings over time to enable more efficient query scheduling.
