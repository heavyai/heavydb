title: foreign_storage::PassThroughBuffer
description: "PassThroughBuffer wraps a pointer with specifed data size."
---

`PassThroughBuffer` wraps a pointer with specifed data size.

This class does not take ownership of the pointer. The underlying buffer is never intended to be modified only read, hence the constructor takes a `const` pointer.

```cpp showLineNumbers={false}
#include <foreign_storage/PassThroughBuffer.h>
```

**Inherits from:** `Data_Namespace::AbstractBuffer` (public)
