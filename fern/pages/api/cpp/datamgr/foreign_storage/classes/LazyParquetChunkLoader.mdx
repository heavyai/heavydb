### loadChunk [#loadchunk]

<CodeBlock links={{"LazyParquetChunkLoader": "lazyparquetchunkloader", "RowGroupInterval": "../structs/rowgroupinterval", "Chunk": "../../chunkns/classes/chunk", "ChunkMetadata": "../../structs/chunkmetadata"}}>
```cpp showLineNumbers={false}
std::list<std::unique_ptr<ChunkMetadata>> foreign_storage::LazyParquetChunkLoader::loadChunk(
    const std::vector<RowGroupInterval> &row_group_intervals,
    const int parquet_column_index,
    std::list<Chunk_NS::Chunk> &chunks,
    StringDictionary *string_dictionary = nullptr,
    RejectedRowIndices *rejected_row_indices = nullptr
)
```
</CodeBlock>

Load a number of row groups of a column in a parquet file into a chunk.

NOTE: if more than one chunk is supplied, the first chunk is required to be the chunk corresponding to the logical column, while the remaining chunks correspond to physical columns (in ascending order of column id.) Similarly, if a metada update is expected, the list of [ChunkMetadata](../../structs/chunkmetadata) shared pointers returned will correspond directly to the list `chunks`.

**Returns:** An empty list when no metadata update is applicable, otherwise a list of [ChunkMetadata](../../structs/chunkmetadata) shared pointers with which to update the corresponding column chunk metadata.

**Parameters**

<ParamField path="parquet_column_index" type="const int">
- The logical column index in the parquet file (and omnisci db) of column to load
</ParamField>

<ParamField path="chunks" type="std::list<Chunk_NS::Chunk> &">
- A list containing the chunks to load
</ParamField>

<ParamField path="string_dictionary" type="StringDictionary *" default="nullptr">
- A string dictionary for the column corresponding to the column, if applicable
</ParamField>

<ParamField path="rejected_row_indices" type="RejectedRowIndices *" default="nullptr">
- Optional, if specified errors will be tracked in this data structure while loading
</ParamField>

### loadRowGroups [#loadrowgroups]

<CodeBlock links={{"LazyParquetChunkLoader": "lazyparquetchunkloader", "RowGroupInterval": "../structs/rowgroupinterval", "Chunk": "../../chunkns/classes/chunk", "ForeignTableSchema": "foreigntableschema"}}>
```cpp showLineNumbers={false}
std::pair<size_t, size_t> foreign_storage::LazyParquetChunkLoader::loadRowGroups(
    const RowGroupInterval &row_group_interval,
    const std::map<int, Chunk_NS::Chunk> &chunks,
    const ForeignTableSchema &schema,
    const std::map<int, StringDictionary *> &column_dictionaries,
    const int num_threads = 1
)
```
</CodeBlock>

Load row groups of data into given chunks.

Note that only logical chunks are expected because the data is read into an intermediate form into the underlying buffers. This member is intended to be used for import.

NOTE: Currently, loading one row group at a time is required.

**Returns:** [num_rows_completed,num_rows_rejected] - returns number of rows loaded and rejected while loading

**Parameters**

<ParamField path="row_group_interval" type="const RowGroupInterval &">
- Specifies which row groups to load
</ParamField>

<ParamField path="chunks" type="const std::map<int, Chunk_NS::Chunk> &">
- Map of column index to chunk which data will be loaded into
</ParamField>

<ParamField path="schema" type="const ForeignTableSchema &">
- Schema of the foreign table to perform metadata scan for
</ParamField>

<ParamField path="column_dictionaries" type="const std::map<int, StringDictionary *> &">
- A map of string dictionaries for columns that require it
</ParamField>

<ParamField path="num_threads" type="const int" default="1">
- Number of threads to utilize while reading (if applicale)
</ParamField>

### suggestColumnMapping [#suggestcolumnmapping]

<CodeBlock links={{"LazyParquetChunkLoader": "lazyparquetchunkloader"}}>
```cpp showLineNumbers={false}
SQLTypeInfo foreign_storage::LazyParquetChunkLoader::suggestColumnMapping(
    const parquet::ColumnDescriptor *parquet_column
)
```
</CodeBlock>

Suggest a possible Parquet to OmniSci column mapping based on heuristics.

NOTE: the suggested type may be entirely inappropriate given a specific use-case; however, it is guaranteed to be an allowed mapping. For example, geo-types are never attempted to be detected and instead strings are always suggested in their place.

**Returns:** a supported OmniSci `SQLTypeInfo` given the Parquet column type

**Parameters**

<ParamField path="parquet_column" type="const parquet::ColumnDescriptor *">
- The column descriptor of the Parquet column
</ParamField>
