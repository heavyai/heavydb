### populate_string_ids [#populatestringids]

<CodeBlock links={{"StringDictionary": "stringdictionary"}}>
```cpp showLineNumbers={false}
void StringDictionary::populate_string_ids(
    std::vector<int32_t> &dest_ids,
    StringDictionary *dest_dict,
    const std::vector<int32_t> &source_ids,
    const StringDictionary *source_dict,
    const std::vector<std::string const *> &transient_string_vec = {}
)
```
</CodeBlock>

Populates provided `dest_ids` vector with string ids corresponding to given source strings.

Given a vector of source string ids and corresponding source dictionary, this method populates a vector of destination string ids by either returning the string id of matching strings in the destination dictionary or creating new entries in the dictionary. Source string ids can also be transient if they were created by a function (e.g LOWER/UPPER functions). A map of transient string ids to string values is provided in order to handle this use case.

**Parameters**

<ParamField path="dest_ids" type="std::vector<int32_t> &">
- Vector of destination string ids to be populated
</ParamField>

<ParamField path="dest_dict" type="StringDictionary *">
- Destination dictionary
</ParamField>

<ParamField path="source_ids" type="const std::vector<int32_t> &">
- Vector of source string ids for which destination ids are needed
</ParamField>

<ParamField path="source_dict" type="const StringDictionary *">
- Source dictionary
</ParamField>

<ParamField path="transient_string_vec" type="const std::vector<std::string const *> &" default="{}">
- Ordered vector of string value pointers
</ParamField>
