Abstract prototype (interface) for a data manager.

A data manager provides a common interface by inheriting the public interface of this class, whose methods are pure virtual, enforcing each class that implements this interfact to implement the necessary methods.

A data manager literally manages data. One assumption about the data manager is that it divides up its data into buffers of data of some kind, each of which inherit the interface specified in [AbstractBuffer](abstractbuffer) (

```cpp showLineNumbers={false}
#include <Data_Namespace/AbstractBufferMgr.h>
```

**See also:**
[AbstractBuffer](abstractbuffer)).
