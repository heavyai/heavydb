a Templated version of Data_Namespace::ThrustAllocator that can be used as a custom allocator in thrust device containers such as thrust::device_vector.

Note that this class derives from thrust::mr::allocator in order to meet the requirements of an [Allocator](../../classes/allocator)

```cpp showLineNumbers={false}
#include <Data_Namespace/TypedThrustAllocator.h>
```

## Example

```cpp showLineNumbers={false}
// creates a thrust allocator on device 0
ThrustAllocator thrust_allocator(data_mgr, 0);
// creates a device vector that allocates storage via the above ThrustAllocator
thrust::device_vector<int, TypedThrustAllocator<int>>
vec(10, TypedThrustAllocator<int>(thrust_allocator));
```
