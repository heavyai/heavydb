<CodeBlock links={{"Chunk": "chunk", "AbstractBuffer": "../../classes/abstractbuffer"}}>
```cpp showLineNumbers={false}
std::shared_ptr<Chunk> Chunk_NS::Chunk::getChunk(
    const ColumnDescriptor *cd,
    AbstractBuffer *data_buffer,
    AbstractBuffer *index_buffer,
    const bool pinnable = true
)
```
</CodeBlock>

Compose a chunk from components and return it.

Note, the `index_buffer` is only applicable if the column is a variable length column. If the column type is not variable length, this parameter is ignored.

**Returns:** a chunk composed of supplied components

**Parameters**

<ParamField path="cd" type="const ColumnDescriptor *">
- The column descriptor for the chunk
</ParamField>

<ParamField path="data_buffer" type="AbstractBuffer *">
- The data buffer for the chunk
</ParamField>

<ParamField path="index_buffer" type="AbstractBuffer *">
- The (optional) index buffer for the chunk
</ParamField>

<ParamField path="pinnable" type="const bool" default="true">
- Sets the chunk as pinnable (or not)
</ParamField>
