### appendData [#appenddata]

<Tabs>
<Tab title="Overload 1">

<CodeBlock links={{"ParquetStringEncoder": "parquetstringencoder"}}>

```cpp showLineNumbers={false}
void foreign_storage::ParquetStringEncoder<V>::appendData(
    const int16_t *def_levels,

    const int64_t values_read,
    const int64_t levels_read,

```
</CodeBlock>

Appends Parquet data to the buffer using an in-place algorithm.

Any necessary transformation or validation of the data and decoding of nulls is part of appending the data. Each class inheriting from this abstract class must implement the functionality to copy, nullify and encode the data.

Note that the Parquet format encodes nulls using Dremel encoding.

**Parameters**

<ParamField path="def_levels" type="const int16_t *">
- An array containing the Dremel encoding definition levels
</ParamField>

<ParamField path="rep_levels" type="const int16_t *">
- An array containing the Dremel encoding repetition levels
</ParamField>

<ParamField path="values_read" type="const int64_t">
- The number of non-null values read
</ParamField>

<ParamField path="levels_read" type="const int64_t">
- The total number of values (non-null & null) that are read
</ParamField>

<ParamField path="values" type="int8_t *">
- Values that are read
</ParamField>
