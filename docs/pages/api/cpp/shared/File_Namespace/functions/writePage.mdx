Writes a page from buf to the file.

**Returns:** size_t The number of bytes written (should be equal to pageSize).

**Parameters**

<ParamField path="f" type="FILE *">
Pointer to the FILE.
</ParamField>

<ParamField path="pageSize" type="const size_t">
The logical page size of the file.
</ParamField>

<ParamField path="pageNum" type="const size_t">
The page number to where data is being written.
</ParamField>

<ParamField path="buf" type="int8_t *">
The source buffer from where data is being read.
</ParamField>
