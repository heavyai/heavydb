Reads the specified page from the file f into buf.

**Returns:** size_t The number of bytes read (should be equal to pageSize).

**Parameters**

<ParamField path="f" type="FILE *">
Pointer to the FILE.
</ParamField>

<ParamField path="pageSize" type="const size_t">
The logical page size of the file.
</ParamField>

<ParamField path="pageNum" type="const size_t">
The page number from where data is being read.
</ParamField>

<ParamField path="buf" type="int8_t *">
The destination buffer to where data is being written.
</ParamField>

<ParamField path="file_path" type="const std::string &">
Path of file to read from.
</ParamField>
