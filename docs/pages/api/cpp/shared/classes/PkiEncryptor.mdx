### generateEncryptionCertificateIfNotExists [#generateencryptioncertificateifnotexists]

```cpp showLineNumbers={false}
void PkiEncryptor::generateEncryptionCertificateIfNotExists()
```
</CodeBlock>

Generates a new encryption certificate at the set key store path, if one does not already exist.

Generated certificate file is only readable and writable by the owner of the server process.

Extracts the public key from encryption certificate at the set key store path and encrypts provided plain text using this key.

**Returns:** A serialized series of cipher text segments resulting from encryption
