Validates that the given file path is allowed.

Validation entails ensuring that given path is not under a blacklisted root path and path is under a whitelisted path, if whitelisted paths have been configured. Also excludes the use of spaces and punctuation other than: . / _ + - = :

**Parameters**

<ParamField path="file_path" type="const std::string &">
- File path to validate
</ParamField>

<ParamField path="data_transfer_type" type="const DataTransferType">
- Enum indicating whether validation is for an import or export use case
</ParamField>

<ParamField path="allow_wildcards" type="const bool" default="false">
- Bool indicating if wildcards are allowed
</ParamField>
