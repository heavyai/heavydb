An umbrella column var holding all information required to generate code for subcolumns.

Note that this currently inherits from [ColumnVar](columnvar), not the [GeoExpr](geoexpr) umbrella type, because we use the same codegen paths regardless of columnvar type.

```cpp showLineNumbers={false}
#include <Analyzer/Analyzer.h>
```

**Inherits from:** `Analyzer::ColumnVar` (public)
