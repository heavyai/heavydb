A middle-layer class that can be inherited from to gain modify rights to a [RelAlgDag](../classes/relalgdag) class.

This provides a way to access private members of the [RelAlgDag](../classes/relalgdag) class without dirtying its public interface with non-const accessors that may only apply for very specific classes. Only classes/structs that inherit from this middle-layer class will have modify rights.

```cpp showLineNumbers={false}
#include <RelAlgDag.h>
```
