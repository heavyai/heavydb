Loads constructor data and instantiates TableDescriptor-dependent classes by loading the table name and accessing its table descriptor from a thread-local catalog reference.

NOTE: for proper overload resolution of [boost::serialization::load_construct_data](loadconstructdata) while maintaining templatization on [RelAlgNode](../../../../classes/relalgnode) type, this function is specialized on the Archive type, in this case boost::archive::text_iarchive. This would break if other archives are used.
