### castConstantFromDecimal [#castconstantfromdecimal]

<CodeBlock links={{"DotProductVisitor": "dotproductvisitor"}}>
```cpp showLineNumbers={false}
void DotProductVisitor::castConstantFromDecimal(
    SQLTypeInfo const &return_type,
    Analyzer::Expr *expr
) const
```
</CodeBlock>

Conditionally add a cast to constant decimal expressions because it is unwieldy to carry their precision and scale into the dot_product calculation.

### homogenizeArrayExpr [#homogenizearrayexpr]

<CodeBlock links={{"DotProductVisitor": "dotproductvisitor"}}>
```cpp showLineNumbers={false}
std::shared_ptr<Analyzer::Expr> DotProductVisitor::homogenizeArrayExpr(
    SQLTypeInfo const &return_type,
    std::shared_ptr<Analyzer::Expr> expr
) const
```
</CodeBlock>

When an [Array](../structs/array) is encountered under a DOT_PRODUCT(), if its elements are decimal, cast them to return_type_ by castConstantFromDecimal().

If the array consists only of constants, then return it as a [Constant](constant) so that it can be hoisted with CgenState::getOrAddLiteral().
