Driver for running cleanup processes on a table.

`TableOptimizer` provides functions for various cleanup processes that improve performance on a table. Only tables that have been modified using updates or deletes are candidates for cleanup. If the table descriptor corresponds to a sharded table, table optimizer processes each physical shard.

```cpp showLineNumbers={false}
#include <TableOptimizer.h>
```

### recomputeMetadata [#recomputemetadata]

<CodeBlock links={{"TableOptimizer": "tableoptimizer"}}>
```cpp showLineNumbers={false}
void TableOptimizer::recomputeMetadata() const
```
</CodeBlock>

Recomputes per-chunk metadata for each fragment in the table.

Updates and deletes can cause chunk metadata to become wider than the values in the chunk. Recomputing the metadata narrows the range to fit the chunk, as well as setting or unsetting the nulls flag as appropriate.

### vacuumDeletedRows [#vacuumdeletedrows]

<CodeBlock links={{"TableOptimizer": "tableoptimizer"}}>
```cpp showLineNumbers={false}
void TableOptimizer::vacuumDeletedRows() const
```
</CodeBlock>

Compacts fragments to remove deleted rows.

When a row is deleted, a boolean deleted system column is set to true. Vacuuming removes all deleted rows from a fragment. Note that vacuuming is a checkpointing operation, so data on disk will increase even though the number of rows for the current epoch has decreased.
