This is a helper class for performing GPU reduction code.

It uses the same functions that [ResultSetReductionJIT](resultsetreductionjit) generates so that it can be reused and help the reduction procedure within GPU.

```cpp showLineNumbers={false}
#include <ResultSetReductionJIT.h>
```
