Annotates internal functions with function attributes designating the function as one which does not modify memory, does not throw, does not synchronize state with other functions/parts of the program, and is guaranteed to return.

This allows the LLVM optimizer to more aggressively remove / reorder these functions and is particularly important for dead code elimination.

```cpp showLineNumbers={false}
#include <AnnotateInternalFunctionsPass.h>
```
