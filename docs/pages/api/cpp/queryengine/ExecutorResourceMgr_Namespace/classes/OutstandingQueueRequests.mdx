@type `OutstandingQueueRequests`

Stores and allows access to a binary semaphore per [RequestId](../typedefs/requestid) (using an `std::unordered_map`), as well as accessing all outstanding RequestIds for waiting requests

Submits a request with id `request_id` into the queue, waiting on a `BinarySemaphore` until [`ExecutorResourceMgr`](executorresourcemgr) decides to grant the request resources and wakes the waiting thread.

If it waits for a period longer than `max_wait_in_ms`, a [`QueryTimedOutWaitingInQueue`](querytimedoutwaitinginqueue) exception is thrown.
