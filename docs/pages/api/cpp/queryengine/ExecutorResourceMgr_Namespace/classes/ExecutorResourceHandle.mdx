A wrapper returned by [`ExecutorResourceMgr`](executorresourcemgr) to the requestee, containing the [ResourceGrant](../structs/resourcegrant) that was granted.

When this class goes out of scope (i.e. the executing thread finishes its query step, the destructor will automatically instruct [`ExecutorResourceMgr`](executorresourcemgr) to release the granted resources back to the [`ExecutorResourcePool`](executorresourcepool).
