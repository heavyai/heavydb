A container for various stats about the current state of the [`ExecutorResourcePool`](../classes/executorresourcepool).

Note that [`ExecutorResourcePool`](../classes/executorresourcepool) does not persist a struct of this type, but rather builds one on the fly when `ExecutorResourcePool::get_resource_info()` is called.

```cpp showLineNumbers={false}
#include <ExecutorResourceMgr_Namespace/ExecutorResourcePool.h>
```
