Specifies all `DataMgr` chunks needed for a query step/request, along with their sizes in bytes.

It also keeps track of other metadata to avoid having to recompute this info, such as total_bytes and a vector of total byte sizes for each kernel. The latter is relevant if `bytes_scales_per_kernel` is true, as the [`ExecutorResourceMgr`](../classes/executorresourcemgr)/ [`ExecutorResourcePool`](../classes/executorresourcepool) can scale back the number of kernels allowed to run simultaneously to ensure that a query step can run.
