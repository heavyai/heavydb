Stores current key statistics relating to [`ExecutorResourceMgr`](../classes/executorresourcemgr) state, particularly around the number of requests in queue and currently executing.

Some of these stats are used to populate the system table `executor_pool_summary`, and in the future they may be used along with the [`RequestStats`](requeststats) vector to learn from query patterns for more efficient scheduling.

