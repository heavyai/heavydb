Protected warp synchornization to make sure all (or none) threads within a warp go through a synchronization barrier.

thread_pos: the current thread position to be used for a memory access row_count: maximum number of rows to be processed The function performs warp sync iff all 32 threads within that warp will process valid data NOTE: it currently assumes that warp size is 32.
